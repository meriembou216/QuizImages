# Quiz en images (Android, Kotlin)

Jeu de quiz de 5 questions illustrées (formes géométriques). Pour chaque
question, l'utilisateur choisit une réponse parmi 3 boutons. Le score et la
progression sont affichés, avec un écran final et un bouton Rejouer.

## Ouvrir et lancer l'application
1. Cloner le dépôt : `git clone https://github.com/meriembou216/QuizImages.git`
2. Ouvrir le dossier dans Android Studio (File > Open).
3. Attendre la synchronisation Gradle.
4. Choisir un émulateur (ou un téléphone) et cliquer sur Run ▶.

## Contenu du dépôt
- `app/` : code Kotlin (`MainActivity.kt`), layout XML, images (drawable)
- `captures/` : captures d'écran de l'application
- `compte-rendu/` : compte rendu du travail
